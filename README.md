# 📚 Online Library System

A modern, feature-rich online library application built with **React 18**, **Vite**, **React Router**, and **Redux**. Browse books by category, view details, add new books, and enjoy a seamless user experience.

## ✨ Features

### ✅ Home Page (15 marks)
- Welcome message with engaging hero section
- Browse books by category (Fiction, Non-Fiction, Sci-Fi, Mystery)
- Display popular books as attractive cards
- Quick access navigation

### ✅ Browse Books Page (20 marks)
- Filter books by category with dynamic routing (`/books/:category`)
- Search functionality to find books by title or author
- Display books in an easy-to-scan list format
- View details link for each book

### ✅ Book Details Page (15 marks)
- Dynamic route (`/book/:id`) displaying full book information
- Book title, author, description, rating, and price
- Add to cart and wishlist buttons
- Back to browse button for easy navigation

### ✅ Add Book Page (30 marks)
- User-friendly form to add new books
- Form validation for all fields
- Redux state management for books
- Custom book icon selection
- Success message on submission
- Automatic redirect to Browse Books page

### ✅ 404 Page Not Found (5 marks)
- Custom 404 page for undefined routes
- Displays invalid route URL
- No header component (as per requirements)
- Quick links back to valid pages

### ✅ Styling & UX (5 marks)
- Modern CSS styling with gradients and transitions
- Responsive design for all screen sizes
- Professional color scheme and typography

### ✅ Code Quality
- Comprehensive comments throughout codebase
- Redux for global state management
- React Router for client-side routing
- Form validation with error messages
